
# PDF AI Assistant

## Project Overview
An interactive PDF Question Answering application built using Streamlit, LangChain, ChromaDB, and Ollama.

## Features
- Upload PDF documents.
- Ask questions about uploaded PDFs.
- Generate AI-powered answers.
- Display retrieved document chunks.
- Show response generation time.
- Maintain conversation history.
- Clear chat history.

## Technologies Used
- Python
- Streamlit
- LangChain
- ChromaDB
- Ollama
- Llama 3.2
- Nomic Embed Text

## How to Run

1. Install the required libraries:

   pip install -r requirements.txt

2. Start Ollama and ensure the required models are installed.

3. Run the application:

   streamlit run app.py
